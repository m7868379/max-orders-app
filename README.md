# 📦 MAX Messenger Mini App: Автоматизация заказов и логистики

Мини-приложение для мессенджера MAX (и веб-клиентов), заменяющее ручной ввод с бумажных бланков на автоматизированный прием оптовых и розничных заявок.

Полностью бессерверная архитектура (Zero-VPS / Serverless). Разработано при экспертной поддержке AI.

## 🚀 Архитектура решения
- **Frontend (Витрина и Диспетчерская):** Vanilla JS + Vue 3 + Tailwind CSS (без Node.js сборщиков).
- **Backend / Database:** [Supabase](https://supabase.com) (PostgreSQL в облаке).
- **Админка контента:** Google Таблицы + Google Apps Script (мгновенная синхронизация каталога и курьеров).
- **Связь в реальном времени:** Supabase Realtime (WebSocket-оповещения диспетчера о новых заказах со звуком).
- **Логистический пайплайн:** Stepper-трекер этапов (Новый ➔ В сборке ➔ Собран ➔ В пути ➔ Вручен).
- **Аналитика:** Event Sourcing логов (`order_events`) и SQL View с расчетом маржинальности и COGS.

## 🛠 Быстрый старт для разработки
1. Склонируйте репозиторий: `git clone https://github.com/m7868379/max-orders-app.git`
2. Скопируйте файл конфигурации:
   `cp js/config.example.js js/config.js`
3. Укажите ваши `SUPABASE_URL` и `SUPABASE_ANON_KEY` в `js/config.js`.
4. Откройте `index.html` (витрина) или `admin.html` (диспетчерская, PIN: `7788`) прямо в браузере.
